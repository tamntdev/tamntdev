### Lunar Reminder & Greeting Card Studio
*A smart Vietnamese Lunar-Solar event reminder and customizable greeting card creator with voice-activated scheduling.*

**Stack:** Flutter / SwiftUI (MVVM) · Custom Canvas · Voice Recognition · Astronomical Calendar Algorithms

- Implemented precise Vietnamese Lunar-Solar calendar conversion algorithms, including leap-month calculation and recurring annual reminders
- Voice-triggered event creation allowing users to schedule reminders hands-free using natural speech
- Interactive custom canvas editor for designing, previewing, and exporting personalized greeting cards
- Local push notification scheduling with zero external server dependency

### PinStory — Location-Based Memory Journal
*An interactive map journaling app that anchors personal stories and photos to real-world geographic coordinates.*

**Stack:** Kotlin · Jetpack Compose · MapLibre · Goong Map API

- Modern declarative native UI built with **Jetpack Compose** featuring custom map markers and smooth bottom-sheet transitions
- Vector map rendering and accurate Vietnamese address geocoding powered by **MapLibre** and **Goong API**
- Interactive timeline and spatial clustering to browse memories by location or date
